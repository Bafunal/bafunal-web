ABOUT NGS XS BAFUNAL

One ecosystem. Many directions.

BAFUNAL brings together a growing set of software ideas under one ecosystem. The goal is to develop tools that can move from programming and game technology to creator software and system software.

This site is designed as the public home for those projects, with GitHub as the place for source code, releases and development progress.
